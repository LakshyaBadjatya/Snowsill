# Contributing to Snowsill

Snowsill is developed by **Lakshya Badjatya**. The code is public so you can see exactly what the app does and help make it better.

## Ways to help

- **Report a bug.** Open an issue with your macOS version, your Mac model, what you did and what happened. A screenshot or short screen recording helps a lot.
- **Suggest a feature.** Open an issue describing what you'd like and why.
- **Send a fix.** Pull requests are welcome. Keep them small and focused, and explain the change in plain words.

## What a good change looks like

- It keeps Snowsill light: smooth at the display's refresh rate with low CPU use.
- It needs no new permissions. Snowsill works without Screen Recording or Accessibility.
- It adds no tracking, analytics or new network calls.
- Logic changes in `Sources/SnowsillCore` come with a test in `Tests/SnowsillCoreTests`.
