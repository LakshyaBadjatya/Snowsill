# Snowsill privacy policy

**Snowsill collects no personal data. It has no accounts, no analytics and no tracking.**

| What | Why | Leaves your Mac? |
|---|---|---|
| Position and size of on-screen windows, the Dock and desktop widgets | So snow can land on them | No |
| Pointer position | So you can push snow around | No |
| Your settings | Remembered between launches | No (stored on your Mac) |
| A city name you type (optional, "Match the weather in my city") | Looked up on [Open-Meteo](https://open-meteo.com) to get its current weather | Only the city name and its coordinates |
| Update check (direct download only) | Finds new versions of Snowsill | A plain request for the update feed, with no personal data |

Snowsill never reads window titles, window contents or anything you type. It does not need Screen Recording permission.

The optional **"Precise Dock and desktop icons"** setting asks for Accessibility permission and uses it only to read the size of the Dock and the positions of desktop icons. It is off by default.

Questions: open an issue at https://github.com/LakshyaBadjatya/Snowsill/issues
